操作说明
  • 拖动节点标题移动；从右侧「输出」圆点拖到左侧输入圆点连线。
  • 点击连线选中后按 Delete 删除，或右键连线直接删除。
  • 节点头 ◎ 设为输出节点；× 删除节点（释放其 GPU 资源）。
  • 每次修改都会作为完整候选验证：成功则从第 0 帧启用新修订；失败（如成环）保留旧图继续运行。
  • 「上一帧」节点允许成环：它输出上一完整帧的反馈源，首帧为透明。
  • 暂停 / 单步 / 导出 / 继续共用同一帧编号；导出的 PNG 为普通 sRGB。
